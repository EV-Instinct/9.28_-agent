# ⛵ AI李白 · 望天门山研学助手 (教学专用智能体系统)

> **设计定位**：专为小学语文统编版三年级上册古诗《望天门山》研发的沉浸式数字化教学工作台。  
> **适用场景**：日常多媒体课堂教学、智慧课堂公开课、教师教学技能大赛、信息技术与课程融合课。

---

## 🌟 核心特色与技术亮点

1. **真实鲜活的青年李白人格 (25岁)**
   - 摆脱传统 AI 客板说教，精准塑造 25 岁意气风发、初出蜀道漫游长江的青年李白大哥哥形象。
   - 语言简短亲切，控制在三年级认知范围（2~3 句通俗生动的比喻），绝不使用深奥古代术语。

2. **免费高质感真人配音 (微软 Edge-TTS)**
   - 免配置付费 API Key，采用 `zh-CN-YunyangNeural` 青年朝气男声音色。
   - 李白向全班问好、逐句答疑、朗读点评、颁发奖状全部伴随纯正真人级自然语音输出。

3. **四大教学功能舱（全面覆盖教案需求）**
   - **舱一：行舟伴学·情境答疑** —— 解答字词、“至此回”漩涡与“相对出”相对运动的奇妙视角。
   - **舱二：金石之声·朗读测评** —— **支持对着麦克风直接朗读**：录音经阿里云百炼 Paraformer 转成文字，与标准诗句做**逐字序列比对**（编辑距离），能真正判出漏字、多字与语序颠倒，给出 1~5 星与李白专属朗读锦囊；没有麦克风时可展开手动输入兜底。
   - **舱三：诗境入画·诗画工坊** —— 承接提高层描写任务，将文字转化为 AI 绘图提示词，并在前端渲染出青绿水墨宣纸诗画长卷。
   - **舱四：层楼更上·分层闯关** —— 覆盖 A（基础小书童）、B（提高小画家）、C（拓展小诗人）三阶任务，通关可获得定制研学奖状。

4. **100% 教学比赛级离线容灾策略**
   - **断网不慌**：即使在无外网环境或没有填 API Key 的机房电脑上，系统内置的【教学容灾规则引擎】与【本地水墨长卷渲染器】依然可以流畅运转，杜绝现场报错卡死。
   - **在线可升级**：侧边栏支持任意输入 DeepSeek、通义千问、Kimi 或智谱的 API Key，随时无缝接入最新百亿/千亿大模型。

## 🚀 启动运行方式

### 方式一：双击启动（最简便）
直接双击根目录下的 **`启动天门山研学工作台.bat`** 即可自动拉起系统并在浏览器打开。

### 方式二：命令行启动
```bash
python -m streamlit run app.py
```
终端运行后，浏览器访问：`http://localhost:8501` 即可体验。

## 🎙️ 麦克风朗读使用说明（舱二）

**操作三步**：
1. 切到【舱二：金石之声·朗读测评】，先在下拉框选一句诗；
2. 点录音条上的 **🎤 按钮** → 对着麦克风朗读（读完 **再次点击** 同一按钮停止）；
3. 点 **🚀 开始 AI 朗读测评**，稍候 1~3 秒即可看到「李白哥哥听到的是：……」与星级。

**⚠️ 两个必须注意的前提**：

| 前提 | 说明 |
| :--- | :--- |
| **必须用 `http://localhost:8501` 访问** | 浏览器只允许「安全上下文」调用麦克风。用局域网 IP（如 `http://10.x.x.x:8501`）打开时麦克风会被浏览器直接禁用，此时请改用展开项 **「⌨️ 没有麦克风？可手动输入朗读内容」** 兜底。 |
| **本机需安装 ffmpeg** | 浏览器录音上传的是 `webm/opus` 容器，服务端需用 ffmpeg 转成 16kHz 单声道 WAV 才能送识别。程序会自动在 `PATH` 与常见安装位置（含 WinGet）中查找；若都找不到会打印明确提示。也可用环境变量 `FFMPEG_BINARY` 指定绝对路径。 |

**识别引擎**：阿里云百炼 `paraformer-realtime-v2`，与侧边栏大模型共用 `.env` 中的 `DASHSCOPE_API_KEY` / `LLM_API_KEY`，无需额外配置。

**评分逻辑**：不再是「字符是否出现过」，而是**编辑距离序列比对**。例如把「天门中断楚江开」读成「开江楚天门中断」只会得 2 星并明确指出语序问题，杜绝旧版乱序也能拿满分的漏洞。

## ⏱️ 40 分钟公开课教学实施建议表

| 时间节点 | 教学环节 | 教师与智能体人机协同操作 |
| :--- | :--- | :--- |
| **00~05 分钟** | **情境创设，引人入胜** | 教师大屏打开工作台，点击 **“听李白哥哥亲口打招呼”**，教室响起 25 岁李白豪迈清脆的问候，瞬间引爆学生好奇心。 |
| **05~18 分钟** | **精读诗句，词意探秘** | 进入【行舟伴学舱】，围绕“天门中断”、“楚江开”、“至此回”、“相对出”向李白提问。李白用通俗易懂的生动比喻解释“相对运动”与“长江劈山”。 |
| **18~28 分钟** | **字正腔圆，金石朗读** | 进入【金石之声舱】，挑 2~3 位学生上台或在机房朗读诗句。系统分析断句与重音，给出星星和语音朗读锦囊。 |
| **28~36 分钟** | **分层挑战，诗画融通** | 学生进入【分层闯关阁】：基础薄弱组完成 A 层背诵打卡；中等组进入【诗画工坊】写下描写并生成水墨图卷；学优组在 C 层仿写小诗与李白对答。 |
| **36~40 分钟** | **成果展示，颁发勋章** | 投屏展示学生们共创的水墨长卷，系统一键生成带有学生姓名的 **《天门山研学结业证书》**，升华对祖国壮丽山河的自豪与热爱。 |
